# 鹈鹕兜风 · Pelican Freewheel

一个可以调整视角的 3D 鹈鹕骑自行车动画网页。全部模型由立体几何构建；页面、样式和 Three.js 均随项目提供，运行时不依赖外部 CDN。

## 打开网页

在此目录运行 `node serve.mjs`，然后打开 <http://127.0.0.1:4173>。需要已安装 Node.js。由于浏览器对本地模块的限制，请通过预览地址打开，不要直接双击 HTML。

## 操作

- 鼠标拖动 / 手机单指拖动：旋转视角。
- 鼠标滚轮 / 手机双指缩放：调整远近。
- 立体、侧面、正面、俯视：切换预设机位。
- 播放按钮或空格：暂停 / 继续；暂停时仍可调整视角。
- 滑杆：调整骑行速度；自动环绕：持续绕场景观察。
- 方向键：旋转；加号和减号：缩放；重置按钮：恢复默认视角。

## 文件

- `dist/index.html`：网页入口。
- `dist/style.css`：桌面及手机界面。
- `dist/scene.js`：3D 模型、同步踩踏动画及交互。
- `dist/vendor/`：Three.js 0.186.0 与对应 MIT 许可。
- `serve.mjs`：仅绑定本机回环地址的静态预览服务。

## 已完成的检查

桌面 1440 × 1000 与手机 390 × 844 画面已检查。预设视角、拖动旋转、滚轮缩放、键盘控制、调速、暂停恢复、自动环绕及脚蹼与踏板对齐均已验证。通过浏览器移动设备模拟验证单指旋转和双指缩放；不是实体手机测试。遵循系统“减少动态效果”偏好，首次加载时暂停。

页面附带可选 WebMCP 动画控制接口。已在 Codex 内置浏览器验证接口注册、有效输入与界面一致、无效速度被拒绝且不会改变原有状态。普通网页功能不依赖此接口。

参考：[Three.js OrbitControls 官方文档](https://threejs.org/docs/pages/OrbitControls.html)。

完整静态网页位于 `dist/` 目录，Sites 项目配置位于 `.openai/hosting.json`。发布时使用与 Git 提交一致的静态文件。
